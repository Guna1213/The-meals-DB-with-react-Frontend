# 🍽️ MealDB App

A responsive **Meals Collection** web application powered by the [TheMealDB API](https://www.themealdb.com/).  
Browse, search, and filter meals by name, category, cuisine area, or alphabetical letter.  
Users can also add custom meals to the collection.

## ✨ Features
- 🔍 Search meals by name
- 🔤 Filter by letter (A–Z)
- 🏷️ Filter by category (Dessert, Vegetarian, etc.)
- 🌍 Filter by area/cuisine
- ➕ Add custom meals
- 📱 Fully responsive design

## 🛠️ Tech Stack
- React.js
- MealDB REST API
- CSS / Tailwind (update as needed)
- React Router

## 🚀 Getting Started
\```bash
git clone https://github.com/your-username/mealdb-app.git
cd mealdb-app
npm install
npm start
\```
